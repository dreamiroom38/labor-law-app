# 노동법전 (labor-law-app)

공인노무사 업무용 노동법령 조회 웹앱입니다. PC 브라우저와 휴대폰 홈 화면(PWA)에서 사용합니다.

- 법령 출처: 국가법령정보센터(law.go.kr) Open API만 사용
- 수록 법령: 노동 관계 법령 21개(시행령·시행규칙 포함)와 민법

## 지금 들어 있는 것

- `mockup/index.html`: 화면 시안 3개(첫 화면, 법령 화면, 검색 결과). 실제 법령 데이터가 아니며, 조문·개정 목록은 모두 "예시" 자리 채움 글입니다.
